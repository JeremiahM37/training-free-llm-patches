# research/

Durable state for the program in `../research.md`. Resume order: `research_state.md` → `next_actions.md` → `decisions.md`.
Literature: `literature/papers.jsonl` (harvest, deduplicated), `literature/reading_notes/` (what was actually read).
Hypotheses: `hypotheses/hypothesis_registry.md`. Experiments have IDs `E###`; every result JSON records model revision, data version, config, seeds, hardware.
Raw API responses and full texts are git-ignored and can be regenerated with `tools/`.
